    这个实验是怎样算出来的？

    当前位置的斜率是 2x。沿着斜率的反方向走一点，就是这里的一次更新

    下一步 x = x − α × 2x

    手算第一步：2 − 0.1 × 2 × 2 = 1.6

    展开数学解释与模型边界

    更新式也可以写成 xₖ₊₁ = (1 − 2α)xₖ。每一步都乘同一个数，所以可以直接判断结果。

    • 0 < α < 0.5：在同一侧逐渐接近 0
    • α = 0.5：一步到达 0
    • 0.5 < α < 1：在两侧交替接近 0
    • α = 1：非零初值在正负两侧持续振荡
    • α > 1：非零初值的绝对值越来越大
    • α = 0 时不移动；初值为 0 时一直停在最低点

    这些结论针对 f(x)=x²。复杂函数和神经网络的训练有更多条件，不能直接照搬这个学习率范围。轨迹连线表示离散迭代顺序，不是连续运动的物理路径。
